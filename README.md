# Desafio do Pensionato - C#

Repositório criado para fins de estudo, contendo a resolução do exercício do **Pensionato** do curso de C# do professor **Nélio Alves**.

## 📌 Sobre o Exercício
O programa simula o gerenciamento de quartos de um pensionato que possui 10 quartos (numerados de 0 a 9). O sistema permite:
1. Informar a quantidade de estudantes que vão alugar quartos.
2. Registar o nome, o email e o número do quarto escolhido por cada estudante.
3. Exibir um relatório final ordenado com todos os quartos ocupados e os respetivos inquilinos.

## 🛠️ Tecnologias Utilizadas
- **Linguagem:** C# (.NET)
- **Conceitos aplicados:** 
  - Orientação a Objetos (Classes, Construtores)
  - Vetores (Arrays)
  - Estruturas de repetição e controlo (`for`, `if`)
